# AI Disclosure

> [!IMPORTANT]
> Please read this file before contributing to the project.

This file defines what you can/cannot do with AI to help this project grow.

## Zero Vibe-coding policy

I (Rotwo), as the main contributor of this project, commit to not using any AI-assisted coding tools while building this project. Its whole purpose is for me to learn how to build TUI apps, and having AI write the code for you is not the best way to learn.

Contributors are asked to respect this vision of the project.

## What is allowed

- Using AI for research and understanding concepts.
- Asking how a library works or looking for usage examples in its docs.
- Asking for an explanation of an error message.

## What is not allowed

- Asking AI to write code (functions, files or chunks) for this codebase.
- Using AI-assisted code generation while working on it.
- Submitting pull requests containing AI-generated code.
